# Lab 5.1 - CI para API CRUD de Tasks

Proyecto individual del laboratorio 5.1. Consiste en una API CRUD sencilla construida con Express, con pruebas automatizadas, linting, cobertura y un pipeline de Integración Continua con GitHub Actions.

## Funcionalidades

- GET /health
- GET /tasks
- GET /tasks/:id
- POST /tasks
- PUT /tasks/:id
- DELETE /tasks/:id

## Scripts

```bash
npm install
npm run lint
npm test
npm run test:coverage
npm start
```
